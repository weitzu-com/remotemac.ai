# remotemac.ai

Marketing site for dedicated US Apple Silicon Mac mini rental, operated by CNPS.COM LIMITED.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```

## Deploy on Vercel

This is a Next.js App Router app. Import the Git repository in [Vercel](https://vercel.com/new) (Framework Preset: Next.js). Build command `next build`, output handled by the Next.js runtime. No environment variables are required.

Production domain: [https://remotemac.ai](https://remotemac.ai)
